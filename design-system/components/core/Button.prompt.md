The primary pill-shaped call-to-action button, used for "Start Mission", "Submit Answer", "Sign In", and similar single-verb actions.

```jsx
<Button variant="primary" size="lg" fullWidth>Start Mission</Button>
```

Variants: `primary` (Navy fill — the default, one per screen), `secondary` (Navy outline), `ghost` (text-only, for tertiary actions like "Skip"), `gold` (achievement/celebration contexts only, e.g. "Share your result"). Sizes: `sm` `md` `lg`. `disabled` renders a flat neutral state. Never use `gold` for an ordinary CTA — it's reserved for celebration per the brand's gold-usage rule.
