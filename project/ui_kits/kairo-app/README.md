# Kairo Mobile App — UI Kit

A click-through recreation of the Kairo mobile app, built from the product specifications and screenshots provided (no codebase or Figma file was attached — see root `readme.md` for sources).

**Flow:** Onboarding (5-screen carousel) → Login → Home Dashboard (Today's Mission Card) → Practice (question player → answer feedback) → Session Summary → back to Home, with Review / Insights / Profile reachable from the bottom nav.

Composed entirely from this design system's `components/` — no primitive is re-implemented here. Open `index.html`.
